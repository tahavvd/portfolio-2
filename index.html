Booking & scheduling system

Salon Appointment Booking

A real-time booking flow replacing a paper notebook that caused double-bookings and scheduling chaos.

Live demo ↗ GitHub ↗

Heads up: this demo runs on free hosting that sleeps when idle, so the first load can take up to a minute. That's the hosting, not the app.

Problem
A paper calendar made it easy to double-book clients or leave stylists idle.
Solution
A phone-first booking flow with real availability, plus separate staff and owner workspaces. Availability is rechecked on the server.
Outcome
A complete system: clients book online, staff run their day, and the owner manages services, schedules, and revenue from one dashboard.
  • 14-day availability
  • Service add-ons
  • Safe booking commit
  • Staff & owner dashboards

Inventory & order management system

Inventory Management System

A clean, role-based inventory system for small businesses to track stock, manage orders, and handle suppliers in one place.

Live demo ↗ GitHub ↗

Heads up: this demo runs on free hosting that sleeps when idle, so the first load can take up to a minute. That's the hosting, not the app.

Problem
Manual stock tracking made errors hard to spot and accountability difficult.
Solution
One role-based workspace with live stock per warehouse, a guided order flow, and an automatic transaction history. Orders are checked against real stock on the server, and cancellations restore it.
Outcome
A single source of truth: every stock movement is recorded, low-stock alerts fire before items run out, and each order shows who changed its status and when.
  • Live stock per warehouse
  • Low-stock alerts
  • Order status tracking
  • Admin & employee roles
